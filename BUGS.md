# Bugs

## 1. Fehlende Titel auf den Ranglisten

Auf den Ranglisten wird der Name des Spielers angezeigt, aber nicht sein Titel. Der Titel sollte bei jedem Eintrag mitgeführt werden (z. B. neben dem Namen oder in einer eigenen Spalte).

## 2. Bossgeld bleibt nach dem Verlust der Runde erhalten (Bosslevel)

Wenn im Bosslevel der Boss getötet wird und die Runde danach verloren geht, bleibt das Geld des Bosses beim Spieler. Dadurch lässt sich das Bosslevel beliebig oft wiederholen und so unbegrenzt Geld sammeln. Das Geld aus einer abgeschlossenen Boss-Phase darf bei einem Rundenverlust nicht behalten werden.
